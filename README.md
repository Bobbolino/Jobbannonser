# JobbMatch

JobbMatch är en jobbportal för personer som söker
sitt första arbete inom IT.

## Funktioner

- Visa lediga jobbannonser.
- Filtrera jobb efter kategori och ort.
- Läsa mer om en specifik tjänst.
- Spara intressanta jobbannonser.

## Tillämpade språk

Projektet är byggt med:

- HTML
- CSS
- JavaScript

## Installation

1. Klona projektet från GitHub.
2. Öppna projektmappen i Visual Studio Code.
3. Öppna `index.html` i webbläsaren.
